El problema consiste en desarrollar un aplicativo interactivo en Java que permita al 
usuario realizar diferentes procesos relacionados con operaciones matemáticas y el registro de 
estudiantes. El sistema debe contar con un menú interactivo para facilitar la navegación entre 
las diferentes opciones del programa.
Además, el programa debe permitir almacenar información de varios estudiantes junto 
con sus notas, calcular resultados como promedio, nota mayor, nota menor, cantidad de 
aprobados y reprobados, tomando en cuenta que un estudiante aprueba con una nota mayor o 
igual a 7.
Otro aspecto importante es la persistencia de datos, ya que los resultados obtenidos 
deben guardarse en un archivo de texto para conservar la información incluso después de 
cerrar el programa. También se requiere el uso de validaciones para evitar el ingreso de datos 
incorrectos y garantizar el correcto funcionamiento del sistema.
